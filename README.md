# Chatterbox Teams

Chatterbox Teams is a modern team communication platform built with Next.js, Supabase, and Stripe.

## Features

- Real-time messaging
- Team spaces and channels
- Direct messaging
- User profiles and settings
- Stripe billing integration
- Cloudflare Pages deployment

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment

This project is configured for deployment on Cloudflare Pages using `@cloudflare/next-on-pages`.

To build for Pages:

```bash
npm run pages:build
```
